# Support

This repository is an early public-safe governance hub. Support is best-effort
and community-facing for public-safe questions only.

## Use public issues for

- documentation questions;
- repository boundary questions;
- public-safe resource lane suggestions;
- validation or roadmap clarification.

## Do not use public issues for

- credentials, tokens, cookies, OAuth, cryptographic key material, or account state;
- private configuration;
- private bookmarks or raw browser exports;
- personal memory snapshots or raw conversations;
- local machine paths;
- security-sensitive reports.

## Security or private-data concerns

Use GitHub security advisories when available, or contact the repository owner
privately. Do not post sensitive material in public issues or pull requests.
See `SECURITY.md` for the reporting scope and safe report format.

## Contact and social links

See `docs/contact-and-social.md` for public-safe contact routes and the policy
for adding future social links.

## Scope boundaries

This repository does not provide:

- legal advice;
- security certification;
- guaranteed response times;
- production support;
- private overlay maintenance for other users;
- third-party resource approval outside the documented governance process.
