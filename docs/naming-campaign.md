# Naming Campaign

`open-resource-governance` is a provisional repository slug and temporary
project name. It is accurate for governance work, but it may be too abstract
for developers and users encountering the project for the first time.

The project may be renamed after public feedback.

## Goal

Find a name that is:

- easy to understand without internal context;
- broad enough for resource discovery, Skills governance, bookmark taxonomy,
  and portable AI-collaboration configuration;
- not locked to one agent, vendor, platform, or private workflow;
- short enough for GitHub, social posts, and video captions;
- safe from obvious trademark, domain, or project-name conflicts;
- compatible with the public/private boundary model.

## Submission format

Use the `Name suggestion` issue template and include:

- suggested name;
- optional slug;
- one-line explanation;
- why it fits the project;
- possible downside or ambiguity;
- whether you checked obvious GitHub/search/trademark conflicts.

## Evaluation criteria

Naming feedback is a signal, not automatic authority. The final decision should
consider:

1. clarity for new users;
2. long-term scope fit;
3. memorability;
4. spelling and pronunciation;
5. searchability;
6. low collision risk;
7. low vendor or agent lock-in;
8. community reaction count and comment quality.

## Voting model

Public votes can use GitHub issue reactions or a pinned discussion if
Discussions are later enabled.

The highest vote count should not automatically win. The owner keeps the final
rename gate to avoid names that are popular but confusing, hard to maintain,
legally risky, too narrow, too broad, or inconsistent with the project boundary.

## Decision outcome

Possible outcomes:

- keep `open-resource-governance` for now;
- keep the repository slug but use a clearer public subtitle;
- rename the repository;
- create a new public-facing brand while preserving this repository as a
  governance hub;
- defer the decision until the downstream repositories are more mature.

## Current public wording

Until renamed, refer to the project as:

```text
Open Resource Governance (temporary name)
```

Use the repository URL as the stable discovery path:

```text
https://github.com/yiheng8023/open-resource-governance
```
