# Public / Private Boundary

## Public-safe material

- Repository maps.
- Generic architecture and governance rules.
- Public-safe taxonomy and schemas.
- Placeholder examples.
- Validation scripts.
- Promotion material.

## Private-only material

- Real user configuration.
- Long-term memory snapshots.
- Personal preferences and notes.
- Browser exports and browsing history.
- Credentials, tokens, OAuth, cookies, session data.
- Local machine paths and runtime logs.
- Account, billing, or external-service state.

## Rule

Public repositories are reusable structure and communication surfaces. Private repositories are where real personal state lives.
