# Contributing

Contributions should improve the public-safe system map, documentation, validation, repository relationship model, or promotion material.

Do not contribute private configuration, memory, bookmarks, browsing history, account state, credentials, local paths, private notes, or personal preferences.

## Pull request checklist

- [ ] The change is public-safe.
- [ ] Repository boundaries remain clear.
- [ ] Private-to-public promotion rules are not weakened.
- [ ] License and provenance are clear.
- [ ] `python -B scripts/verify.py` passes.

For issue and pull request routing, see `docs/community-feedback-model.md`.
